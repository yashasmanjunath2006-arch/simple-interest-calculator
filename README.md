
# Simple Interest Calculator

## Description
This project is a Simple Interest Calculator developed using a Bash Shell Script. It calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Requirements
- Linux or Unix operating system
- Bash shell

## How to Run

1. Download or clone this repository.
2. Open the terminal.
3. Navigate to the project folder.
4. Run the following command:

```bash
bash simple-interest.sh
```

## Example

Principal Amount: 1000
Rate of Interest: 5
Time: 2 years

Simple Interest: 100
